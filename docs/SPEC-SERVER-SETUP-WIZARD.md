# SPEC: Server Setup Wizard — web-optimizer/

**Status:** Draft | **Priority:** TIER 2 (high conversion impact)  
**Type:** Interactive 5-step wizard → YAML config export  
**Location:** `web-optimizer/src/app/setup/page.tsx` + `components/setup/`  

---

## Why This Feature

Auto-Tune has good documentation, but new admins are still overwhelmed by config.yml's 50+ parameters. The Server Setup Wizard walks them through 5 decisions and outputs a production-ready YAML snippet. It answers the question: *"Where do I even start?"*

**Conversion hypothesis:** Admins who use the wizard are significantly more likely to complete installation and stay with Auto-Tune long-term vs. those who read the full config guide.

---

## Wizard Steps

### Step 1 — Server Type
**Question:** "What kind of server are you running?"

Options (radio cards, large click targets):
- **SMP / Vanilla+** — "Standard survival. Moderate trading, moderate griefing risk." → Default archetype: 2MM + 2GB
- **Skyblock** — "Island economies, limited resources, high scarcity." → Default archetype: 1MM + 3GB (more demand floor)
- **Faction / PvP** — "High turnover, high exploit risk. Aggressive circuit breaker." → Default archetype: 1MM + 1GB + circuit breaker sensitivity=0.8
- **Economy / Shop** — "Trading-focused, minimal PvP. Tight spreads reward active traders." → Default archetype: 3MM + 1GB (dense liquidity)
- **Custom** — "I'll configure archetypes manually." → Skip archetype recommendation

Visual: Server type icons (pickaxe for SMP, island for Skyblock, swords for Faction, shopping-cart for Economy)

---

### Step 2 — Player Count
**Question:** "How many active players do you expect?"

Slider or button group:
- **Solo/Small** — 1-10 players → baseSpread=0.15 (tighter spreads for low liquidity)
- **Medium** — 10-50 players → baseSpread=0.20 (default)
- **Large** — 50-200 players → baseSpread=0.25 (wider spreads for high volume)
- **Massive** — 200+ players → baseSpread=0.30 (very wide, prevent manipulation)

Side note: "Auto-Tune adapts automatically. This just sets the starting spread."

---

### Step 3 — Economy Goals
**Question:** "What matters most to your economy?"

Multi-select (up to 2):
- **📈 Player Trading Volume** — "Encourage lots of buys and sells. Tighter spreads." → baseSpread -0.05
- **🛡️ Seller Protection** — "Protect sellers from price crashes. Floor at 60%." → enable 60% floor
- **💰 Server Treasury** — "Grow the server's war chest via taxes." → treasury.tax-rate 2-5%
- **⚡ Fast Price Discovery** — "Prices react quickly to new items." → maxPriceChangePercent 2.0
- **🔒 Low Debt** — "Keep players out of trouble. Strict loan limits." → loan.credit-score-multiplier 1.5, post-default-cooldown 336h
- **🎮 Fun Volatility** — "Prices that move a lot. Exciting for active traders." → baseSpread +0.10, maxPriceChangePercent 2.5

Each goal adjusts 1-3 specific config values. Display the delta vs. defaults inline.

---

### Step 4 — Stability Preview
**Question:** "Here's how your economy should behave:"

Show a simulation-derived card (pre-computed from sim runs, not live):

- **Projected Buy/Sell Balance:** e.g., "~50% buy ratio" or "~60% buy ratio"
- **Projected Volatility:** "Low (0.05-0.10)" / "Moderate (0.10-0.15)" / "High (0.15+)"
- **Debt Risk:** "Low (D/G < 2x)" / "Moderate (2-5x)" / "High (circuit breaker likely)"
- **Spread Width:** "Tight (BPD 1-2%)" / "Normal (2-4%)" / "Wide (4%+)"
- **Time to Stability:** "3-5 days" / "1-2 weeks" / "Already stable"

Source these from the 840-config parameter sweep data keyed by archetype × spread × goals.

Also show:
- **Recommended Archetype Config:** e.g., "2 MarketMakers + 2 GuildBuyers @ 5% threshold"
- **Key parameters to tune after 1 week:** e.g., "baseSpread if spreads feel too wide"

---

### Step 5 — Export Config
**Output:** Full `config.yml` snippet to copy-paste.

Sections to include:
```yaml
# Auto-Tune Config — Generated by Setup Wizard
# Server type: SMP | Players: 10-50 | Goals: Seller Protection + Low Debt

economy:
  baseSpread: 0.20        # Starting spread (0.15=tight, 0.30=wide)
  spread:
    floor-percent: 60     # Floor: items can't drop below 60% of base price
  loans:
    counter-cyclical: true
    post-default-cooldown-hours: 336   # 14 days (low debt goal)
    credit-score-multiplier: 1.5       # Stricter loan approval (low debt goal)

player-archetypes:
  MarketMaker:
    count: 2
    threshold: 5          # % below target price to start buying
  GuildBuyer:
    count: 2
    threshold: 5
```

Below the YAML:
- **"Download as config.yml"** button → triggers browser download
- **"Open in Simulator"** link → pre-fills `/simulator` with these parameters
- **"Need help? Join Discord"** link → #autotune

## Component Structure

```
src/app/setup/page.tsx          — Main wizard page (use client)
src/components/setup/
  wizard-context.tsx            — React context: currentStep, answers, dispatch
  server-type-selector.tsx      — Step 1: radio cards
  player-count-selector.tsx     — Step 2: slider/button group
  economy-goals-selector.tsx    — Step 3: multi-select chips
  stability-preview.tsx         — Step 4: simulation-derived cards
  config-export.tsx            — Step 5: YAML display + download
  wizard-nav.tsx                — Back/Next/Step indicators
```

**State shape:**
```typescript
interface WizardAnswers {
  serverType: 'smp' | 'skyblock' | 'faction' | 'economy' | 'custom' | null;
  playerCount: 'solo' | 'medium' | 'large' | 'massive' | null;
  goals: ('volume' | 'seller_protection' | 'treasury' | 'fast_discovery' | 'low_debt' | 'fun_volatility')[];
}

interface WizardState {
  currentStep: 1 | 2 | 3 | 4 | 5;
  answers: WizardAnswers;
}
```

## Dependencies

- Pre-computed stability data from `public/data/setup-wizard-stability.json` (bundled JSON from sim runs)
- `js-yaml` package for YAML generation (`npm install js-yaml`)
- `downloadjs` or native `Blob` + `URL.createObjectURL` for file download
- No API calls needed — fully client-side

---

## Stability Data Source

The stability preview cards are pre-computed from the 840-config parameter sweep + archetype mix tests. Key mappings:

| Server Type | Archetype Config | Base Spread | Goals → delta |
|---|---|---|---|
| SMP | 2MM + 2GB @ 7% | 0.20 | +seller_protection → +60% floor |
| Skyblock | 1MM + 3GB @ 7% | 0.20 | +seller_protection → +60% floor |
| Faction | 1MM + 1GB @ 7% | 0.25 | +low_debt → stricter loans |
| Economy | 3MM + 1GB | 0.15 | +volume → -0.05 spread |
| Custom | user picks | 0.20 | per goal selections |

Store these as a static JSON at `public/data/wizard-archetypes.json`.
